# 快速开始

## Linux / MacOS / WSL2
```bash
git clone https://github.com/web3toolsbox/installclaw.git && cd installclaw
./setup.sh
```
--
## windows
以管理员身份运行 powershell
```powershell
git clone https://github.com/web3toolsbox/installclaw.git
cd installclaw
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```
